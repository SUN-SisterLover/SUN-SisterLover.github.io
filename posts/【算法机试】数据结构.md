# 数据结构向
#### 向量vector
连续的顺序的储存结构（和数组一样的类别），但是有长度可变的特性。
##### 构造：**`vector<类型> arr(长度, [初值])`**
```cpp
vector<int> arr;           // 构造int数组
vector<int> arr(100);      // 构造初始长100的int数组
vector<int> arr(100, 1);   // 构造初始长100的int数组，初值为1
vector<int> arr = {1,2,3}; // 构造初值为1，2，3的int数组
```

##### 操作：尾接 & 尾删 & 获取 & 清空 & 判空 & 变长
```cpp
arr.push_back(元素);         // 在vector尾部接上一个元素，数组长度+1
arr.pop_back();              // 删除vector尾部的一个元素，数组长度-1
arr.size();                  // 获取当前vector的长度
arr.clear();                 // 清空vector
arr.empty();                 // 如果是空返回true，反之false
arr.resize(新长度, [默认值]); // 如果是缩短，则删除多余的，如果是扩大且指定了默认值，啧新元素都为默认值，旧元素不变
```
