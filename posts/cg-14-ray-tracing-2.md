# 14-Ray Tracing 2

> 承接 **`13-Ray Tracing 1`**：射线–隐式面/球、三角与平面、Möller–Trumbore、朴素场景求交与 **AABB / Slab** 见前篇。本文 **Ray Tracing 2** 依次：**均匀网格**（含 Bresenham 画格）、**KD-Tree 与射线遍历**、**Object partition 与 BVH**（及与 SAH 的衔接）。

## 空间划分（Spatial partitions）

把场景空间切成若干区域，使射线求交时**只访问可能含几何的单元**，而不是对全场景图元做线性扫描。常见形态包括**均匀网格**、**八叉树**、**k-d 树**、**BSP 树**以及后文要写的 **BVH**（也常与 AABB 结合）。

## 均匀网格（Uniform grid）

### 建树（更准确说：建「格」）的三步（课件）

1. **Find bounding box**：为整个场景（或当前物体集合）找一个**包围盒**，作为网格的放置范围。
2. **Create grid**：把该包围盒在每条轴上等分成固定分辨率（课件图示为 **8×8** 的二维格子；三维则是体素网格）。
3. **Store each object in overlapping cells**：对每个物体，把它**登记进所有与之相交的格子**里（课件里用**浅灰格**表示：圆与哪些格有重叠，就把该物体指针放进那些格的列表）。

### 射线查询时在干什么（课件）

射线 $\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}$ 穿过网格时：

- **Step through grid in ray traversal order**：按射线前进方向，**依次经过**一串格子（课件里用**浅蓝格**表示访问顺序）。
- **For each grid cell**：只与该格中**登记过的物体**做求交；命中点（课件红点）落在的格可再强调为**深蓝格**。

这样把「射线 × 全场景」变成「射线 × **只经过的少量格** × **每格里少量物体**」。

### 「画格子」与 Bresenham 中点算法

课件上把射线走过的格子**逐个高亮**（画格子），本质上是在做一件事：给定一条连续射线，求它与**离散格边**相交时，**下一个进入哪一格**的顺序。

- **Bresenham 中点线算法**（2D 光栅化直线）：用**整数增量 + 中点判别**决定下一个像素，避免每步做昂贵浮点除法；思想是「沿离散格点**一步一步走**」。
- **和均匀网格射线遍历的对应**：在 2D 均匀网格上沿射线「一格一格走」、确定要经过哪些方格，常用与 Bresenham **同类的增量步进**（或 **DDA**）；三维均匀网格里更常直接实现 **Amanatides–Woo** 一类「求下一个与坐标平面对齐的格边界」的算法，但与 Bresenham 一样，核心是**增量式离散穿越**，而不是对每个格做笨重几何判定。
- **写法上可以记一句**（与课上一口习惯对齐）：**画射线所经格子 / 可视化 traversal order 时，用 Bresenham 中点算法（或其增量思想）确定格序列**；若写生产光追，三维格遍历再对照 **Amanatides & Woo (1987)** 实现即可。

## 三种空间划分对比

同一组圆（物体），不同划分方式（2D 示意；注意维度与标签对应关系）：
![](images/ComputerScience/计算机图形学/Pasted%20image%2020260515171202.png)

| 结构           | 划分方式（要点）                                           |
| ------------ | -------------------------------------------------- |
| **Oct-Tree** | 区域**递归四等分**（3D 为八等分）；密几何处格更细，层次规则、轴对齐。             |
| **KD-Tree**  | 每次用**与坐标轴对齐**的切割线把空间分成两半，切割位置**不必在中点**，常按物体分布平衡左右。 |
| **BSP-Tree** | 切割线/面可取**任意朝向**，两半空间为凸划分；表达力强，但射线与斜切割求交成本相对高。      |

## KD-Tree 怎样和光线追踪一起工作

**k-d 树**把场景空间递归切成两半：每次选 **split axis**（$x$ / $y$ / $z$ 之一）和 **split position**（该轴上的分裂坐标），得到左右（或上下、前后）两块**轴对齐**子区域；子区域继续切，直到叶子里物体足够少或达到最大深度。
![](images/ComputerScience/计算机图形学/Pasted%20image%2020260515171450.png)
### 节点里存什么

- **内部节点（internal）**：**split axis**、**split position**、指向两个子节点的 **children**；**不存放任何物体**（物体只在叶子里维护列表，避免在分裂面上重复存储）。
- **叶子节点（leaf）**：**object list**——落在该叶对应空间区域内的几何（三角形等）的列表。

实现里每个节点通常还缓存一块 **AABB**（或区间包围盒），供射线先做**粗测**。

### 射线遍历算法（与主射线 / 阴影射线同一套）

记射线 $\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}$，当前维护的**最近命中**参数为 $t_{\mathrm{hit}}$（初始可为 $+\infty$ 或表示「尚无交」）。

1. **从根进入**：若射线与**根节点包围盒**无交，直接返回无交。
2. **遇到内部节点**：该节点对应一张**与坐标轴对齐的分裂平面**。根据射线与平面的相对位置，可知射线先进入哪一侧子空间、后进入哪一侧；遍历时常按 **$t$ 从小到大**（先近后远）把**待访问子树**压栈或入队，这样一旦在某个叶子里求出足够小的 $t_{\mathrm{hit}}$，**尚未遍历、且入口 $t$ 已大于 $t_{\mathrm{hit}}$ 的子树**可以整枝剪掉（求最近交时尤其重要）。
3. **遇到叶子节点**：只对叶中 **object list** 做射线–图元求交（如 Möller–Trumbore），用得到的正根更新 $t_{\mathrm{hit}}$。
4. **结束条件**：栈空，或剩余子树已不可能给出比 $t_{\mathrm{hit}}$ 更近的交。

阴影射线若只问「中间有没有挡」，可在**第一次**命中（或 $t$ 小于到光源距离）时提前返回。

### 与课件示意图的对应（帮助脑补）

课件用 **A、B、C、D** 表示四次分裂（竖–横–竖–横），得到 **1～5** 五块叶区域：

- 根 **A** 把全图分成左叶 **1**（蓝）与右半；右半再被 **B** 分成上叶 **2**（绿）与下半；下半被 **C** 分成左链 **D** 与右叶 **3**（橙）；**D** 再分成上叶 **4**（紫）与下叶 **5**（红）。
- 若某条射线在空间上**只穿过 2、4、3**，从未进入 **1、5**，则遍历树时**根本不会落到叶 1、叶 5**，这两叶里的物体**零次**求交——这就是加速来源。
- 另一张图在橙区 **3** 内标出 $t_{\mathrm{hit}}$：表示**最近命中**发生在叶 3 的物体上；**D–4–5** 子树若射线不与对应盒相交，或盒的最近端 $t$ 已大于当前 $t_{\mathrm{hit}}$，即可**不再访问**（课件里用变淡表示剪枝）。

### 用 A、B、C、D 这张图：KD 树「在判断什么」、叶和父节点各是什么

先对齐课件符号（避免和「彩色块」混在一起想）：

- **A、B、C、D**：是**内部节点**在图上的**标注**，对应四次**分裂平面**（竖线 A、横线 B、竖线 C、横线 D）。在数据结构里，它们存的是 **split axis + split position + 左右子指针**，**不存三角形**；图里画成线/标签，就是在标「**从这里把空间切成两半**」。
- **1、2、3、4、5（蓝绿橙紫红五块）**：是**叶子节点**对应的**最终子区域**——空间已经切到「不再往下分」的那一层。**物体（三角形等）只挂在这些叶的 `object list` 里**（课件上的小圆）；父节点中间**没有**「再存一份几何」。

因此你问的「**是不是最后一个区域都是（三角形）在子节点里面**」：更准确说——**三角形只在叶子里**；**A～D 不是「区域」而是「划分」**，父节点是**决策点**，不是「中间塞满标注以外的几何」的那块面。

下面用**同一张 A→B→C→D 的树**，说明射线从根往下走时，**每一层在判断什么**（与课上从左图走到右图一致）：

1. **在根 A（竖直分裂）**  
   先判断射线与**整场景根盒**是否相交；有交后，看射线与**竖直线 A** 的关系：射线从 $t=0$ 出发沿 $\mathbf{d}$ 走，会先在 A 的**左侧**进入空间、还是**右侧**？两侧子树各自对应一块**子包围盒**（左：叶 1 那块蓝区；右：B 子树那一整块）。若射线与**左子盒**根本不相交（或最近进入 $t$ 已经不可能落到蓝区），就**整枝跳过叶 1**，只往 **B** 那边走。

2. **在 B（水平分裂）**  
   对「A 的右侧、B 的子树」那一整块盒，再判断射线与**水平线 B**：先进入 B **上方**（可能去叶 **2** 绿区）还是 **下方**（去 **C**）？同样先做**子盒与射线**的相交测试，无交则那一整支子树不递归。

3. **在 C（竖直分裂）**  
   在 B 下方那一块里，射线与**竖直线 C**：先左（进入 **D** 子树，紫/红 4、5）还是先右（直接去叶 **3** 橙区）？

4. **在 D（水平分裂）**  
   只在「C 的左侧、D 的子树」里才出现：再分上是叶 **4**、下是叶 **5**。射线若根本不进这一支，**4、5 里的三角形一次都不会被测**。

**小结成一句**：父节点 **A～D** 上的判断，全是「**射线下一步进哪半边空间、哪棵子树的盒还与射线有交**」；**只有落到叶 1～5 时**，才对那个叶里的 **object list** 做昂贵的射线–三角形求交。所以你看到「父节点中间都是标注」这种直觉**基本对**：**中间层主要是分裂与指针；几何在叶里。**

下面转到**按物体聚类**的 **BVH**（与 KD 的「切空间」对照着记）。

## Object partition 与 BVH（Bounding Volume Hierarchy）

课件标题常写成 **Object Partitions & Bounding Volume Hierarchy (BVH)**：不再切「空的空间」，而是把**物体集合**递归分成两堆，每堆外包一个 **AABB**，再在盒子上建树。

### Spatial vs Object（课件对照，和 KD 放一起看）

| | **Spatial（如 KD-Tree）** | **Object（如 BVH）** |
| --- | --- | --- |
| 划分对象 | **空间** → 互不重叠的子区域 | **物体集合** → 互不相交的子集（每块三角只归一边） |
| 边界 | 区域之间**不重叠** | 子集的 **AABB 在空间上可以重叠**（保守包围必然松） |
| 同一三角 | 可**跨多个区域**，多叶重复引用 / 多次测试风险 | 通常**只属于一侧子集**，叶列表不重复划分 |

### 建树三步（课件 + 左图右树）

左图：灰框分别包住蓝、绿、黄三角簇，**框与框可交叠**；右图：根再分到「蓝 + 绿」与「黄」两支，左支再分成**蓝叶**与**绿叶**——内部节点是**聚合与划分**，叶子里才是**具体三角**。

1. **Find bounding box**：对当前节点里的**全体物体**算一个**公共紧包围盒**（根即全场景盒）。
2. **Recursively split set of objects in two subsets**：按启发式把物体**分成两子集**（见下）。
3. **Recompute the bounding box of the subsets**（课件**加粗**强调）：**对左右子集分别重新算 AABB**，不能偷懒沿用父盒几何上硬切——子盒必须**紧贴各自子集里的三角**，后面射线–盒测试才有效。

### 怎么划分一个节点（课件启发式）

这些在 **KD** 建树与 **BVH** 建树里**口径常一起讲**，记成「当前节点上怎么下刀」即可：

- **选轴**：启发式 **#1**——选**当前节点 AABB 最长**的那条轴（$x$ / $y$ / $z$），避免子盒过分细长。
- **选分裂位置 / 分堆规则**：启发式 **#2**——在选定轴上，常按**物体重心在该轴的坐标**排序，取 **median（中位数）** 把物体**均分成两堆**，使树**较平衡**，期望深度 $O(\log n)$。
- **终止**：启发式 **#3**——当节点内物体个数 $\le$ 某阈值（课件例：**5**）就**不再划分**，直接作为**叶**。

### 射线求交：`Intersect(ray, node)`（课件伪代码）

```text
Intersect(ray, node):
    if ray 与 node.bbox 无交:
        return 无交
    if node 是叶:
        对叶中所有 objs 做射线–图元求交
        return 这些交里最近的（或写入全局 t_hit）
    hit1 = Intersect(ray, node.child1)
    hit2 = Intersect(ray, node.child2)
    return hit1 与 hit2 中更靠近射线起点的那个交
```

要点：**每一层先 AABB（Slab）**， miss 则整支剪掉；**只有叶**才跑 Möller–Trumbore 等重计算。朴素写法对两子**都递归**再比远近；实现上常按**射线先进入哪侧子盒**（沿 $t$ 更近）**调整递归顺序**，并结合当前最优 $t_{\mathrm{hit}}$ **提前剪掉**另一子树（与 KD 遍历里的剪枝同一精神）。

### SAH（表面积启发，一句占位）

比「最长轴 + 中位数」更好：在若干**候选切分**里，用**左右子盒表面积 × 子集三角数**等代价估计「这一刀划得值不值」；作业 **SAH** 版 BVH 再按课推导把公式抄全即可。
