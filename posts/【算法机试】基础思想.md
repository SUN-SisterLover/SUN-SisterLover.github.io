# Sort排序

**用法示例**
```cpp
template< class RandomIt, class Compare >
void sort( RandomIt first, RandomIt last, Compare comp );
```

默认排序为：从小到大
```cpp
vector<int> arr{1, 9, 1, 9, 8, 1, 0};
sort(arr.begin(), arr.end());
// arr = [0, 1, 1, 1, 8, 9, 9]
```

如果要从大到小，则需要传入一个比较器
```cpp
vector<int> arr{1, 9, 1, 9, 8, 1, 0};
sort(arr.begin(), arr.end(), greater<int>());
// arr = [9, 9, 8, 1, 1, 1, 0]
```

如果需要完成一些特殊的比较，那么则需要手写比较器。比较器函数返回值是 bool 类型，传参是需要比较的两个元素，比较器中传入的两个参数分别是a和b，如果返回了true，那么a就在b的前面，如果返回false，那么a就在b的后面或者等价。
```cpp
bool cmp(pair<int, int> a, pair<int, int> b)
{
    if (a.second != b.second)
        return a.second < b.second;
    return a.first > b.first;
}

int main()
{
    vector<pair<int, int>> arr{{1, 9}, {2, 9}, {8, 1}, {0, 0}};
    sort(arr.begin(), arr.end(), cmp);
    // arr = [(0, 0), (8, 1), (2, 9), (1, 9)]
}
```

# 贪心

**适用范围**：贪心算法在有最优子结构的问题中尤为有效．最优子结构的意思是问题能够分解成子问题来解决，子问题的最优解能递推到最终问题的最优解．

**两种证明方法**：
- 反证法：如果交换方案中任意两个元素/相邻的两个元素后，答案不会变得更好，那么可以推定目前的解已经是最优解了
- 1. 归纳法：先算得出边界情况（例如 𝑛 =1![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "n = 1")）的最优解 𝐹1![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "F_1")，然后再证明：对于每个 𝑛![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "n")，𝐹𝑛+1![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "F_{n+1}") 都可以由 𝐹𝑛![](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7 "F_{n}") 推导出结果．

**两种解法**：
- 排序算法：用排序法常见的情况是输入一个包含几个（一般一到两个）权值的数组，通过排序然后遍历模拟计算的方法求出最优值．
- 后悔解法：思路是无论当前的选项是否最优都接受，然后进行比较，如果选择之后不是最优了，则反悔，舍弃掉这个选项；否则，正式接受．如此往复

#### 某个数的幂
两种思路，一种是不断除计算，一种是使用最大公倍数去刷
```cpp
// 不断计算，就是算是否能到n == 1（因为最小的情况是n == 1
class Solution {
public:
    bool isPowerOfThree(int n) {
        while( n > 0 && n % 3 == 0)
        {
            n /= 3;
        }
        return n == 1;
    }
};
```

#### 转置矩阵
[867. 转置矩阵 - 力扣（LeetCode）](https://leetcode.cn/problems/transpose-matrix/?envType=study-plan-v2&envId=primers-list)
两种解法，一种是提前构造好形状，填数，一种是一点一点插进去。
```cpp
// 填数
class Solution {
public:
    vector<vector<int>> transpose(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        vector<vector<int>> result;
        for(int i = 0; i < n; i++)
        {
            vector<int> row;
            for(int j = 0; j < m; j++)
            {
                row.push_back(matrix[j][i]);
            }
            result.push_back(row);
        }
        return result;
    }
};
```

```cpp
class Solution {
public:
    vector<vector<int>> transpose(vector<vector<int>>& matrix) {
        int m = matrix.size();          // 原矩阵行数
        int n = matrix[0].size();       // 原矩阵列数（你问的子数组长度）
        // n 行，每行 m 个 0 —— 这就是转置后的尺寸
        vector<vector<int>> result(n, vector<int>(m));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                result[j][i] = matrix[i][j];
            }
        }
        return result;
    }
};
```
