# 计算机网络概述

## 定义

**计算机网络**是以能够相互共享资源的方式互联起来的**自治计算机系统的集合**。可以从以下 4 个方面理解：

1. 计算机网络建立的主要目的是实现**资源共享**；
2. 互联的计算机是分布在不同地理位置的多台独立的"**自治计算机**"；
3. 连网计算机之间的通信必须遵守共同的网络**协议**；
4. 互联计算机之间的连接需要有一条通道，即由**传输介质**实现物理互联。

## URL（统一资源定位符）

- `http://`：超文本传输协议
- `www.xxx.com`：域名地址
- 真正网络中的地址是 **IP 地址**
- 因为域名好记，所以用 **DNS（域名解析系统）** 把域名解析为 IP 地址

## P2P

**P2P**（peer-to-peer communication）：对等通信网络。

例如下载一个文件：

- **C/S 模式**：从服务器直接获取，所有流量都走服务器
- **P2P 模式**：把文件分成若干份，同时下载的用户互相分享自己已下载的部分，相当于每个用户既下载又上传，速度大幅提升

## 基本概念

- **ISP**（Internet Service Provider）：互联网服务提供商
- **节点**（node）：计算机、交换机、路由器等构成网络的硬件都可以称为网络中的节点
- **主机**（host）：通过网络为其它机器提供服务的计算机，也称**服务器**
- **客户端**（client）：指从主机处获得服务的计算机，也称为**终端**

## ISP 分级

```
主干 ISP → 地区 ISP → 本地 ISP → 个人用户 / 校园网 / 大公司
```

## 报文与分组

- **报文**（message）：网络中交换与传输的数据单元（例如 `1100110010100…`）
- **分组**（packet）：为了从源端系统向目的端系统发送一个报文，源端将长报文划分为较小的数据块

## 网络分类

| 分类维度 | 类型 |
| :--- | :--- |
| **分布范围** | 广域网（WAN）、城域网（MAN）、局域网（LAN）、个域网（PAN） |
| **使用者** | 公用网、专用网 |
| **交换方式** | 电路交换、报文交换、分组交换 |
| **拓扑结构** | 星型、总线型、环型、树型、网状型 |
| **传输介质** | 双绞线、同轴电缆、光纤、无线 |
| **用途** | 教育、科研、商业、企业、政府 |

## 三种数据交换方式对比

### 电路交换

**优点：**

1. 通信时延小，实时性强，可靠性高；
2. 数据可以有序传输，安全性好，实现简单。

**缺点：**

1. 建立连接时间长；
2. 线路独占，利用率低，灵活性差。

### 报文交换

**优点：**

1. 线路利用率高，提供多目标服务；
2. 不用建立连接，动态分配线路；
3. 提高了线路的可靠性和利用率。

**缺点：**

1. "存储-转发"导致实时性差；
2. 对报文大小无限制，存储空间需求大；
3. 发生错误时需要请求重传，整个报文都要丢弃重发。

### 分组交换

**优点：**

1. 存储空间开销小；
2. 无效传输低；
3. 传输延迟低。

**缺点：**

1. 分组乱序：各个分组可能通过不同路径到达目的站点；
2. 通信效率低（分组头占额外开销）。

# 物理层

在 OSI 参考模型中，物理层指的是**物理信道**。

## 传输介质

- **双绞线**：分为有屏蔽的（**STP**）和无屏蔽的（**UTP**），看使用场景
- **光纤**：光源 + 传输介质 + 检测器，结构由外向内是塑料封套 → 包套玻璃 → 玻璃芯
- **同轴电缆**：屏蔽性比双绞线更好、带宽更大，但已被光纤取代
- **无线**：无线广播、微波、红外线、激光

## 单模光纤 vs 多模光纤

| 维度 | 单模光纤 | 多模光纤 |
| :--- | :--- | :--- |
| 传输距离 | 远 | 近 |
| 带宽 | 大 | 小 |
| 成本 | 高 | 低 |
| 适用场景 | 长距离骨干网 | 局域网、设备互联 |

## 传输标准命名规则

### 以 `1000BASE-TX` 为例拆解

```
1000  BASE  -  T  X
 ↑     ↑        ↑  ↑
速率   类型     介质 编码
```

各字段含义：（这里可能有问题）

- **`1000`**：传输速率，1000 Mbps（1 Gbps）。
- **`BASE`**：基带（baseband）信号，一根线缆只传一个信号；与之相对的是 **`BROAD`**（宽带，broadband），一根线缆能传多个信号（罕见，如 `10BROAD36`）。
- **`T`**：介质为 **T**wisted Pair 双绞线。常见介质后缀：
    - `T`：双绞线
    - `F`：光纤
    - `C`：同轴电缆
- **`X`**：编码方式。具体含义随上下文变化：
    - `100BASE-TX`（百兆）中 `-X` → **4B/5B** 编码（再经 MLT-3 编码）
    - `1000BASE-X` / `10GBASE-X`（千兆/万兆光模块）中 `-X` → **8B/10B** 编码

### 完整字段对照表

|  字段位置  | 取值                                             | 含义                                  |
| :----: | :--------------------------------------------- | :---------------------------------- |
| **速率** | `10` / `100` / `1000` / `10G` / `40G` / `100G` | Mbps 或 Gbps                         |
| **类型** | `BASE`                                         | **基带**信号，一根线缆只传一个信号                 |
|        | `BROAD`                                        | **宽带**信号，一根线缆能传多个信号（罕见）             |
| **介质** | `T`                                            | **T**wisted Pair 双绞线                |
|        | `F`                                            | **F**iber 光纤                        |
|        | `C`                                            | **C**o-axial 同轴电缆                   |
| **编码** | （无后缀）                                          | 曼彻斯特编码（仅适用于 10 Mb/s 级，如 `10BASE-T`） |
|        | `X`                                            | 4B/5B（百兆）或 8B/10B（千兆/万兆），视上下文而定     |
|        | `R`                                            | 64B/66B（万兆以太网 10GBASE-R 系列）         |

> 速记：`-T` 看铜，`-F` 看光，编码后缀（`-X` / `-R`）决定怎么把数据塞进物理信号里。

## 编码

- **归零编码（RZ，Return-to-Zero）**：正电平代表逻辑 1，负电平代表逻辑 0，每传输完一位数据，信号返回到零电平。
- **不归零编码（NRZ，Non-Return-to-Zero）**：与归零编码相比，NRZ 编码不需要归零。
- **反向不归零编码（NRZI，Non-Return-to-Zero Inverted）**：信号**翻转**表示 0，**不翻转**表示 1。
- **曼彻斯特编码**：位中间跳变，**1 是高→低**，**0 是低→高**。
- **差分曼彻斯特编码**：位中间**始终跳变**（与曼彻斯特相同）；位开始处**不跳变表示 1**，**跳变表示 0**（约定可相反）。

> 曼彻斯特与差分曼彻斯特都属于"自带时钟"的编码，每位中间都有跳变，接收方可以用这个跳变同步时钟，因此广泛用于以太网。

## 数字调制

为了发送数字信息，必须设法用模拟信号表示比特（数字信息）。**比特与代表它们的信号之间的映射过程称为数字调制**。

- **码元**：数字调制过程中用来承载信息的基本信号单位，通过特定的映射关系，将一组比特与一个独特的信号状态对应起来。
- 数字信号调制成模拟信号有三种基本方式：**调幅、调频、调相**。

## 波特率 vs 比特率

- **波特率（B）**：单位时间内传输的**码元个数**，单位为**波特（Baud）**，表示信号传输速率（关注物理信号的变化，即底层通信速率）。
- **比特率（C）**：单位时间内传输的**比特个数**，单位为**比特（bit）**，表示数据传输速率（关注实际传输的数据量，即有用信息速率）。

**码元速率与比特率的关系：**

$$
C = B \log_2 N
$$

其中 $N$ 是码元的离散状态数（每个码元所能表示的不同状态数）。

> 例如 $N = 4$ 时，每个码元可承载 $\log_2 4 = 2$ bit，所以比特率是波特率的 2 倍。

## 正交振幅调制（QAM）

在频率相同的前提下，将调幅和调相结合，形成叠加信号：

$$
C = B \log_2(MN)
$$

其中 $M$ 是相位数，$N$ 是振幅数，乘在一起就是码元的离散状态数。（一般是十六状态数的码元）

## 奈奎斯特定理（奈氏准则）

无噪声情况下，码元速率的极限值 $B$ 与信道带宽 $H$ 的关系：

$$
B = 2H \quad \text{(Baud)}
$$

$H$ 为信道带宽（信道能传输的上、下限频率之差），单位 Hz。

**无噪声信道的极限传输速率：**

$$
C = 2H \log_2 N \quad \text{(b/s)}
$$

> 提示：奈氏准则只考虑了带宽和码元状态数，**没有考虑噪声**；要想考虑噪声对信道容量的限制，需要用香农公式。

## 香农定理

一条带宽为 $H$、有噪声的信道的**最大传输速率**为：

$$
C = H \log_2\left(1 + \dfrac{S}{N}\right) \quad \text{(b/s)}
$$

其中 $S/N$ 是**信噪比**（信号功率与噪声功率之比）。

> 提示：香农公式给出的 $C$ 是理论极限，无论用多复杂的编码方式都无法突破；要突破只能提高带宽 $H$ 或信噪比 $S/N$。

## 信噪比与分贝

实际中常用**分贝（dB）**表示信噪比：

$$
\text{dB} = 10 \lg\left(\dfrac{S}{N}\right)
$$

| 信噪比 $S/N$ | 分贝值 |
| :---: | :---: |
| 10 | 10 dB |
| 100 | 20 dB |
| 1000 | 30 dB |

> 速记：$S/N$ 每增大 10 倍，dB 增大 10 dB。

## 信道复用

**信道复用**（Channel Multiplexing）是指在有限的物理信道资源上，通过不同方式让多个信号共享同一个信道，以提高资源利用率和通信效率。

信道复用主要从三个维度区分：**频率、时间、编码**。常见的信道复用技术有：

| 技术 | 维度 | 英文 | 说明 |
| :--- | :---: | :--- | :--- |
| **频分多路复用** | 频率 | FDM（Frequency Division Multiplexing） | 将可用带宽划分为多个频段，每个信号占据不同频段 |
| **时分多路复用** | 时间 | TDM（Time Division Multiplexing） | 多个信号按时间片轮流占用整个信道 |
| **码分多路复用** | 编码 | CDM（Code Division Multiplexing） | 又称 CDMA，所有用户在相同频率和时间共享信道，但用不同编码区分 |
| **波分多路复用** | 频率（光） | WDM（Wavelength Division Multiplexing） | 类似 FDM，但用于光纤通信，每个信号用不同波长的光传输 |

> 注：**波分复用本质上是频分复用在光学领域的应用**——光波频率太高不方便直接操作，改用波长区分。

### CDMA 与码片（chip）

**码片**（chip）：在 CDMA 中，一比特会被再细分成多个码片，码片是比比特更短的单位。每个比特由多个码片组成，通常为 64 或 128 个码片。

**码片序列约定：** 计算机网络中每一个节点会被分配一个长度为 $m$ 的码片序列，把比特 0 写作比特 1 的反码（每个分量取反）：

$$
A = (-1, -1, -1, +1, +1, -1, +1, +1) \longleftrightarrow \text{比特 1}
$$

$$
\bar{A} = (+1, +1, +1, -1, -1, +1, -1, -1) \longleftrightarrow \text{比特 0}
$$

#### 三条关键性质

**1. 正交性（区分不同用户）：** 任意两个**不同**节点的码片序列归一化内积为 0。

$$
S \cdot T = \dfrac{S_1 T_1 + S_2 T_2 + \cdots + S_m T_m}{m} = 0
$$

例：

$$
A = (-1, -1, -1, +1, +1, -1, +1, +1),\quad B = (-1, -1, +1, -1, +1, +1, +1, -1)
$$

$$
A \cdot B = \dfrac{1 + 1 - 1 - 1 + 1 - 1 + 1 - 1}{8} = \dfrac{0}{8} = 0
$$

**2. 自相关性：** 任何码片与**自身**的归一化内积一定为 1。

$$
S \cdot S = \dfrac{S_1^2 + S_2^2 + \cdots + S_m^2}{m} = \dfrac{m}{m} = 1
$$

**3. 反码相关性：** 任何码片与**自身反码**的归一化内积一定为 $-1$。

$$
S \cdot \bar{S} = -1
$$

#### 解码（恢复比特流）

为了恢复某个节点的比特流，接收方必须**预先知道这个节点的码片序列**，把收到的码片与目标码片做归一化内积。

例：已知 A 节点的码片序列 $A = (-1, -1, -1, +1, +1, -1, +1, +1)$，收到的码片为 $(-2, 0, 0, 0, +2, +2, 0, -2)$，求 A 发送的比特。

$$
\text{接收码片} \cdot A = \dfrac{(-2)(-1) + 0 \cdot (-1) + 0 \cdot (-1) + 0 \cdot 1 + 2 \cdot 1 + 2 \cdot 1 + 0 \cdot 1 + (-2)(-1)}{8}
$$

$$
= \dfrac{2 + 0 + 0 + 0 + 2 + 2 + 0 + 2}{8} = \dfrac{8}{8} = 1
$$

**约定：**

- 结果 $= +1$ 表示 A 发送的是**比特 1**
- 结果 $= -1$ 表示 A 发送的是**比特 0**
- 结果 $= 0$ 表示**没有数据**（其他用户发的）

封装成帧-比特填充法
使用特定的比特模式作为帧的起始和终止标志，并在数据部分中避免比特模式的冲突。
优点：适用于任何比特流，不局限于字符编码（比字符填充更通用）
缺点：需要额外的比特填充，稍微增加了传输开销

封装成帧-物理层编码法
数据报封装成帧后，直接在物理层使用信号的变化来标识帧的起始和结束，而不是依赖特定的比特模式。
优点：不需要填充比特，不会增加额外的开销
缺点：依赖物理层的编码方式，不适用于所有链路层协议

错误检测
数据在传输过程中，由于各种因素（如干扰、噪声、信号衰减），可能导致比特错误
（比特翻转）。数据链路层提供错误检测机制，保证数据传输的可靠性，使得接收端能检
则出数据的错误并采取相应措施（如请求重传）。

错误检测-奇偶校验（ParityCheck）
奇校验还是偶校验是发送方与接收方事先协商好的
不论是奇校验还是偶校验，判断依据都是数据中1的个数的奇偶性
数据的1的个数+校验位=满足奇校验或偶校验的要求
对于10110101
做偶校验在末尾补成一个101101011（因为此时这个数里面有5个1，是奇数，补一个1）
做奇校验在末尾补成一个101101010（因为此时这个数里面有5个1，是奇数，补一个0）
优点：实现简单，开销小
缺点：检测能力弱，只能检测奇数个比特的错误，偶数个比特错误无法检测

错误检测一校验和（Checksum）
校验和是一种常用的错误检测方法，广泛用于TCP/IP协议中，具体操作方法如下：
·发送方将待发送的数据分成若干段（通常16位为一组）
·将这些数据段进行二进制求和
·若求和过程中产生进位，则将进位部分回卷相加（循环进位）
·最后将求和结果取反，作为校验和附加在数据后发送
·接收方验证后如果结果全部是1说明数无误，否则数据有问题
比如如果发送两个数据段分别是：0110011001100000和0101010101010101。
我们生成一个校验码0100010001001010（两个数据段加起来然后取反）
这样被发送过去之后可以再把这两个数据段加起来，加上校验码如果是1111111111111111就对了

如果发送的数据是1111111111111111和0000000000000001，最后算出来是10000000000000000超了一位，就将其回卷相加，变成0000000000000001，再取反……
优点：比奇偶校验强，能检测更多错误，简单高效，计算量小
缺点：不能检测所有错误（例如数据中部分比特位置翻转后总和仍相同，无法发现）

错误检测-循环冗余校验（Cyclic RedundancyCheck）
<
CRC是一种广泛用于数据链路层的错误检测方法，常用于以太网、HDLC、PPP等协议。
·发送方和接收方事先约定一个叫作生成多项式的二进制序列
·生成多项式如果有n位，发送方在发送数据末尾添加n-1个0

算出来最后是余110，就补上去，也就是最终发送数据为原始数据+CRC码，也就是：
1011001110

传播延迟
传播延迟就是数据或信号从发送节点传到接收节点的时间。

最大传播延迟
最远两个节点之间信号传播的时间，这就是最大传播延迟
它决定了，最坏情况下，发送节点多久才能得知是否发生冲突

争用期（往返传播延迟）
发送节点多久才能得知是否发生冲突
最大传播延迟为T，则争用期为2T

最小帧长
最小帧长的目的，是保证数据帧发送所用的最短时间>往返传播延迟
如果数据帧过小，那么碰撞发生之间监听就停止了，那么就无法检测冲突
最小帧长=争用期（2T）×传输速率

退避时间
后形威
当多个节点同时发现冲突、同时停下后，如果都同时重新发送，一定再冲突
所以设计了随机等待机制（退避），避免持续碰撞
退避时间=争用期（2T）x随机数 k（k E[O, 2"-1]）
n为重传次数，n的值最大为10，重传次数最多16次

无线LAN和有线LAN
在有线局域网中，当一个站发出一帧时，所有其他站都能接收到这个帧。
在无线局域网中，由于无线电传输范围有限，无法向所有的站传输帧，也无法接收来自所有
其他站的帧。
在无线局域网中，相对于发送信号而言，接收到的信号可能很微弱，因此，在无线信道中进
行冲突检测非常困难，硬件成本高。

带碰撞避免的 CSMA（CSMA with Collision Avoidance）
带碰撞避免的 CSMA（CSMAwith Collision Avoidance，CSMA/CA）
节点在发送数据之前监听无线信道，如果信号强度超过一定阀值则认为当前有其他节点在该
信道上发送数据，此时随机等一段时间后再次监听。
如果检测到信道空闲，需要等到一个帧间间隔（InterFrameSpace，IFS）之后再发送数
据，在等待的时候保持监听。

DIFS（Distributed InterFrame Space）分布式帧间间隔：
·用于普通数据帧之间的间隔
·节点在发送数据帧之前，需要监听信道是否空闲，若信道空闲，则等待DIFS时间再发送
SIFS（Short InterFrame Space短帧间间隔：
●用于控制帧（如ACK、RTS/CTS等）之间的间隔
·SIFS是最短的间隔，通常用于控制信道使用的帧。
EIFS（Extened InterFrame Space）扩展帧间间隔：
·主要用于错误帧，例如接收到错误数据的节点在发送ACK前需要等待更长时间。
